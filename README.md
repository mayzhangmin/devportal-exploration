# HSBC Dev Portal MCP

The HSBC Dev Portal MCP helps users discover, compare, and inspect HSBC APIs across markets, brands, and business lines using natural language. It can identify the right API for a use case, explain why it fits, and return concrete integration details such as endpoints, sandbox base URLs, Swagger definitions, and supporting documentation.

Typical questions include finding the right API for customer onboarding in Hong Kong, comparing onboarding versus Open Banking client registration flows, or drilling into the exact contract behind a selected API.
